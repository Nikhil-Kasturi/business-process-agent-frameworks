## About

Most business processes were built for people, paper and spreadsheets, with AI added as an afterthought. Every redesign here starts with the actual process itself. I map how the process runs today, pinpoint where it breaks, and rebuild it as an agentic ecosystem: which agents do the work, where people make the decisions, and what the business gains.

## How each process page is built

**Stage 1: the baseline** (live for all 162)

1. **What it does:** what the function does and why the business depends on it
2. **The traditional flow:** a step-by-step diagram of how it runs today
3. **Where it breaks:** the main pain point

**Stage 2: the What-If redesign** (published process by process)

4. **Tools in use today**
5. **Pain points in depth**
6. **Today's critical user journey**
7. **The What-If agent ecosystem:** the agents, their roles and the human checkpoints
8. **The new critical user journey**
9. **Before and after**
10. **How each pain point gets solved**
11. **Business outcomes**

> Impact figures in any redesign are illustrative estimates, never measured results.
